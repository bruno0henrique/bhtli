# Portfólio bhsti.online

Site pessoal de Bruno Henrique Lopes de Souza, com foco em oportunidades de Desenvolvedor Full Stack Júnior.

## Estrutura

HTML, CSS e JavaScript sem etapa de build. `index.html` apresenta o conteúdo, `app.js` mantém os detalhes dos cards e `styles.css` define a interface responsiva.

Para visualizar localmente, sirva a raiz com um servidor HTTP estático. A publicação é vinculada ao repositório `bruno0henrique/bhtli` na Vercel; domínio público: https://www.bhsti.online.
